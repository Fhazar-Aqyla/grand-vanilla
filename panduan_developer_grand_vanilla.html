Bagian II: Pemahaman Produk & B2B Ekspor

Agar Anda terlihat sangat kompeten dan menguasai materi saat berdiskusi dengan klien vanili, berikut adalah terminologi ekspor vanili yang sudah terintegrasi di dalam website:

Bab 4: Terminologi Ekspor Vanili yang Wajib Anda Kuasai

1. Dua Varietas Utama Vanili Indonesia

  • Vanilla Planifolia (Madagascar-type): Varietas paling populer di dunia. Cirinya pod panjang, tebal, oily, dengan aroma vanillin murni yang kuat dan klasik. Sangat disukai industri makanan, perisa es krim, dan bakery kelas atas.
  • Vanilla Tahitensis: Varietas dengan aroma floral, fruity, dan sentuhan wangi bunga seperti anis. Sangat dicari oleh produsen parfum kelas dunia, kosmetik, serta pastry artisanal premium.

2. Parameter Laboratorium & Klasifikasi Kualitas (Specs)

  • Vanillin Content (2.0% - 2.4%): Kadar vanilin alami hasil analisis laboratorium. Standar ekspor Grade A mensyaratkan vanillin di atas 1.8%. Vanili Jawa Timur dan Papua terkenal memiliki kadar vanillin tinggi karena proses sun-curing tradisional.
  • Moisture Content (30% - 35% untuk Gourmet Grade A): Kadar kelembaban polong. Pod Grade A harus kenyal, lentur (*supple*), dan berkilau minyak alami. Sedangkan untuk *Extraction Grade* kelembaban berkisar 20%-25% (lebih kering dan cocok untuk diekstrak cairan).
  • Pod Length (16 - 20 cm): Ukuran panjang polong vanili utuh. Panjang pod berbanding lurus dengan kematangan saat dipetik di pohon.

3. Ketentuan Pengiriman Internasional (Incoterms & Dokumen Legal)

  • FOB (Free on Board): Penjual bertanggung jawab hingga barang dimuat ke pesawat kargo di Bandara Soekarno-Hatta (CGK Jakarta) atau Ngurah Rai (DPS Bali). Ongkos angkut internasional ditanggung pembeli.
  • CIF (Cost, Insurance, Freight): Penjual menanggung harga barang, asuransi kargo laut/udara, dan biaya pengiriman hingga ke pelabuhan tujuan buyer di luar negeri.
  • Phytosanitary Certificate: Sertifikat jaminan kesehatan tumbuhan bebas hama dari Badan Karantina Pertanian Indonesia. Wajib ada untuk ekspor komoditas vanili.
  • COA (Certificate of Analysis): Laporan hasil uji lab independen mengenai kadar vanillin, kelembaban, dan bebas mikroba patogen.

Bab 5: Pemisahan Database vs File Tema

Mengapa Anda tidak perlu takut salah?
Seluruh teks, gambar, spesifikasi produk, dan data kontak disimpan di database MySQL. File-file tema PHP di folder wp-content/themes/grand-vanilla-theme/ hanya bertindak sebagai "cetakan" tampilan. Jika Anda mengubah teks di admin WordPress, Anda tidak menyentuh kode tema. Cetakan tersebut akan membaca data baru dari database secara otomatis tanpa risiko error.

Bagian IV: Panduan Operasional WP Admin Lengkap (Tambah, Edit, Hapus)

Bagian ini adalah pedoman teknis operasional terlengkap untuk seluruh menu di WordPress Admin Grand Vanilla Indonesia. Setiap modul dijelaskan tuntas: di mana menunya, apa yang bisa ditambahkan, cara mengeditnya, cara menghapusnya, dan di mana hasilnya muncul pada website.

Bab 8: Kontak, Medsos & Google Maps (Theme Settings / Customizer)

Lokasi Menu: WP Admin → menu Theme Settings di sidebar kiri (atau Tampilan → Sesuaikan).

Muncul di Mana: Topbar atas, Header, Footer di semua halaman, Halaman Contact Us, dan tombol melayang WhatsApp.

Aksi Langkah-Langkah di Dashboard Dampak pada Website
TAMBAH / EDIT 1. Buka Theme Settings.
2. Pada kolom WhatsApp Number, masukkan nomor (misal: 087717752085).
3. Pada kolom Email Address, masukkan email (misal: nirwanatim@gmail.com).
4. Pada kolom Google Maps Embed, paste kode iframe atau URL embed dari Google Maps.
5. Klik tombol biru Publish di bagian atas. 		Nomor WhatsApp, email, dan peta Google Maps langsung terupdate seketika di seluruh halaman web tanpa perlu edit file kodingan satu pun.
HAPUS Kosongkan isi kolom input teks yang ingin dihilangkan → klik Publish. Bagian kontak tersebut akan kembali ke nilai bawaan (default) yang aman dan rapi.

Bab 9: Katalog Produk Vanili Utama (Vanilla Products)

Lokasi Menu: WP Admin → menu Vanilla Products.

Muncul di Mana: Halaman Beranda (Featured Products), Katalog Semua Produk (/products/), dan Halaman Detail Produk (/products/[nama-produk]/).

➕
CARA MENAMBAH PRODUK BARU:
  1. Klik menu Vanilla Products → Add New Product.
  2. Judul: Ketik nama produk vanili (contoh: Gourmet Black Planifolia Beans).
  3. Deskripsi: Ketik penjelasan produk, profil aroma, dan kegunaan kuliner di kotak editor utama.
  4. Featured Image: Pada kolom sebelah kanan bawah, klik Set featured image → pilih atau upload foto produk vanili terbaik.
  5. Vanilla B2B Export Specifications (Kotak Bawah): Isi parameter laboratorium:
    • Botanical Name: misal Vanilla planifolia Andrews
    • Grade & Quality: misal Gourmet / Grade A Prime
    • Moisture Content: misal 30% - 35%
    • Vanillin Content: misal 2.0% - 2.4%
    • Pod Length: misal 16 - 22 cm
    • Harvest & Origin: misal East Java & Papua, Indonesia
  6. Klik tombol biru Publish di kanan atas. Produk langsung tayang di katalog ekspor!
✏️
CARA MENGEDIT PRODUK LAMA:
  1. Buka menu Vanilla Products → All Products.
  2. Arahkan kursor ke nama produk → klik Edit.
  3. Ubah teks deskripsi, foto, atau angka spesifikasi lab yang ingin diperbarui.
  4. Klik tombol biru Update di kanan atas. Perubahan langsung aktif seketika.
🗑️
CARA MENGHAPUS PRODUK:
  1. Buka menu Vanilla Products → All Products.
  2. Arahkan kursor ke produk yang ingin dibuang → klik tulisan merah Trash (Tong Sampah).
  3. Apakah aman? 100% AMAN. Produk hanya dipindahkan ke folder Trash database. Tampilan katalog website akan otomatis menyesuaikan diri (layout tetap rapi dan tidak akan bolong).
  4. Cara memulihkan jika salah hapus: Klik tab Trash di bagian atas → arahkan kursor ke produk → klik Restore. Produk akan kembali tayang!

Bab 12: Galeri, Foto Dokumentasi & Media Library

Lokasi Menu: WP Admin → menu Media.

Bab 13: Artikel Blog & Edukasi Pasar Ekspor (Posts)

Lokasi Menu: WP Admin → menu Posts.

Bagian V: Zona Aman & Tindakan Darurat Developer

Gunakan panduan ini sebagai batas aman (*safety boundaries*) saat Anda melakukan pemeliharaan website:

Bab 16: Zona Hijau (Aman Bebas) vs Zona Merah (Hati-Hati)

ZONA HIJAU (100% Bebas Tanpa Takut) ZONA MERAH (Hati-Hati & Cek Syntax)
  • Mengubah data kontak di Theme Settings
  • Menambah atau menghapus produk vanili
  • Mengganti foto galeri penjemuran & curing
  • Membaca dan membalas pesan di Inquiries
  • Menulis dan mempublikasikan artikel blog baru
  • Mengganti foto featured image produk
  • Menghapus pesan spam ke folder Trash
  • Mengubah kode fungsi logika di functions.php
  • Menghapus tanda titik-koma (;) atau kurung di file PHP
  • Menonaktifkan plugin tanpa memahami dependensinya
  • Mengubah nama direktori tema grand-vanilla-theme
  • Mengutak-atik tabel database mentah di phpMyAdmin

Bab 17: Langkah Darurat Jika Tak Sengaja Mengedit Kode & Layar Blank

Langkah Penyelamatan 30 Detik

Jika suatu saat Anda mengedit file PHP lalu website memunculkan layar putih atau pesan error:

1
Buka terminal PowerShell di laptop Anda.
2
Ketik perintah ajaib pengecek syntax PHP berikut lalu tekan Enter: 
php -l "C:\laragon\www\grand-vanilla-id\wp-content\themes\grand-vanilla-theme\functions.php"
3
Terminal akan langsung memberitahu di baris berapa yang salah ketik (misal: syntax error, unexpected token on line 45). Buka baris tersebut, perbaiki titik-koma atau kurungnya, lalu simpan.
4
Jika terminal menghasilkan output No syntax errors detected, website Anda sudah normal kembali 100%!

Bab 18: Kepemilikan Akun Hostinger & Apa yang Perlu Diminta ke Klien

Aturan Emas: Akun Hosting & Domain 100% Milik Klien

Pertanyaan Anda: "Hosting ini harusnya atas nama gw atau klien?"
Jawaban Standar Industri: Akun hosting dan domain HARUS selalu atas nama dan dibeli langsung oleh klien menggunakan email dan pembayaran mereka sendiri.

  • Alasan Finansial: Biaya perpanjangan tahunan (renewal fee) domain dan hosting akan ditagihkan langsung ke kartu/rekening klien. Anda tidak perlu repot menagih uang perpanjangan tiap tahun.
  • Alasan Legal & Keamanan: Aset digital (nama domain dan konten web) adalah hak milik sah perusahaan klien, sehingga mereka memiliki kontrol penuh atas properti bisnis mereka.

Bab 20: SOP Migrasi Laragon ke Hostinger 1-Klik (All-in-One WP Migration)

Sebagai developer yang baru pertama kali meng-onlinekan WordPress, hindari cara manual ekspor SQL phpMyAdmin dan ganti URL database yang rawan error. Gunakan All-in-One WP Migration—plugin standar industri yang otomatis mengurus database, gambar, URL, dan konfigurasi hanya dengan 2 tombol:

1
Export dari Laragon (Laptop Anda):
Buka WP Admin lokal → menu Plugins → Add New → cari dan install plugin All-in-One WP Migration → klik Aktifkan.
2
Di sidebar kiri, klik All-in-One WP Migration → klik Export → klik tombol dropdown Export To → pilih FILE.
Tunggu proses scanning selesai hingga muncul tombol unduh berkedip (misal: DOWNLOAD LOCALHOST-GRAND-VANILLA.WPRESS). Simpan file .wpress ini di laptop Anda.
3
Setup WordPress Polos di Hostinger:
Login ke hPanel Hostinger klien → klik Websites → klik Auto Installer → pilih WordPress.
Isi judul situs dan buat username & password administrator untuk login ke WordPress Hostinger.
4
Import ke Hostinger:
Login ke dashboard WordPress Hostinger baru tersebut → install dan aktifkan plugin yang sama: All-in-One WP Migration.
5
Di menu All-in-One WP Migration → klik Import → pilih Import From: FILE → pilih file .wpress yang sudah diunduh tadi.
Jika muncul popup konfirmasi penimpaan database (*This will overwrite your database...*), klik Proceed.
6
Finishing & Simpan Permalinks:
Setelah import selesai 100%, login kembali ke WP Admin menggunakan kredensial akun lokal Anda. Buka menu Settings (Pengaturan) → Permalinks → langsung klik tombol Save Changes (Simpan Perubahan) sebanyak 2 kali untuk me-refresh struktur link.
