## ⚡ 3. On-Page SEO Checklist
- [x] Heading Hierarchy: Single `<h1>` per page, diikuti `<h2>` dan `<h3>` terstruktur.
- [x] Format Gambar: Seluruh gambar memiliki atribut `alt` deskriptif dalam Bahasa Inggris.
- [x] URL Bersih: Menggunakan WordPress Pretty Permalinks (`/%postname%/`).
- [x] Mobile Friendly: Desain sepenuhnya responsif untuk Desktop, Tablet, dan Mobile.
- [x] Speed Performance: Desain CSS ringan tanpa jQuery/framework builder berat.
